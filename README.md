Codex Sidecar 是一个运行在本机的 **Codex 桌面端侧栏增强工具**。它在账号菜单上方放入一张可折叠卡片，把剩余额度、重置时间、公开重置消息和模型检测集中在一起。展开操作，收起看状态，尽量少占任务列表的空间。

macOS 启动入口名为 **「CodeX 注入版」**。双击一次即可打开 Codex 并加载卡片，无需让终端窗口一直挂着。项目通过本机 CDP 加载界面，保留 Codex 原安装包；当前以源码形式提供安装。

这是社区实验项目，与 OpenAI 无隶属关系。它依赖 Codex 的内部页面结构与消息桥，宿主更新后可能需要适配。

## 能做什么

| 功能 | 使用方式 |
| --- | --- |
| **账号额度** | 显示周额度、5 小时额度的剩余比例与重置倒计时；点击查看准确北京时间。仅展示接口实际提供的窗口。 |
| **Tibo 重置消息** | 从 AIHOT 的公开数据查看额外重置预告、确认状态、核验时间及来源。没有置信度数据时不编造百分比。 |
| **模型知识检测** | 选择当前 Codex 提供的模型和推理强度，发送固定知识问题，识别自然语言回答中的 Gemini 版本。 |
| **「恢复智商」实验按钮** | 向同一组选中模型与推理强度发送固定取值提示，结束后可手动复测。 |
| **独立任务与收尾** | 每次请求建立独立任务，回答结束后自动归档；超时或归档失败可以继续处理原任务，避免重复发问。 |
| **紧凑侧栏** | 支持折叠、深浅色主题、自定义选择菜单；检测结果显示在标题旁，原始回答放在详情中。 |

额度与检测使用 Codex 当前登录会话，无需另填 API Key。检测、恢复请求会消耗账号的正常额度。Tibo 消息只用于展示，**不会兑换重置券或执行额度重置**。

## 从源码安装

### 准备环境

- macOS，以及已经安装、可以正常登录的 Codex 桌面端。
- Node.js **22 或以上**。可用 `node --version` 检查。
- Git 和 Xcode Command Line Tools，后者提供构建所需的 Swift。缺少时运行 `xcode-select --install`，完成系统安装窗口后继续。

本项目没有第三方 npm 运行依赖，**不需要 `npm install`**。

### 生成启动入口

把仓库放在准备长期保留的位置，然后运行：

```sh
git clone https://github.com/Wan-Kai/codex-sidecar.git
cd codex-sidecar
npm run build:launcher
```

构建会在仓库中生成 `CodeX 注入版.app`，并在桌面创建带独立图标的 macOS 原生替身。编译过程不启动 Codex。

1. 如果 Codex 已经打开，先保存工作并用 **⌘Q 完全退出**。
2. 双击桌面的 **CodeX 注入版**。
3. 看到账号菜单上方的卡片后即可使用。也可以将仓库中的 App 拖到 Dock，作为日常入口。

**原始 Codex 图标不会自动加载 Sidecar。** 日常改用这个统一入口即可，无需分别启动两个程序。入口会后台运行加载器；关闭 Codex 后，加载器在连接宽限期结束后退出。

### 安装位置与兼容范围

启动器按顺序检查 `/Applications/Codex.app`、`/Applications/ChatGPT.app`，以及个人 `~/Applications` 中的同名应用，并核对 bundle ID 必须为 `com.openai.codex`。真正的 ChatGPT 应用不会因为同名而被当作 Codex 启动。

放在其他目录时，可在构建时指定：

```sh
CODEX_APP_PATH="/absolute/path/to/Codex.app" npm run build:launcher
```

路径会记入本机启动入口。生成的 App 同时记录当前仓库与 Node 的绝对路径，因此 **移动仓库、更换 Node 安装路径后需要重新构建**；不要将生成的 App 单独发给他人。当前不提供签名、公证的一键安装包。

宿主端到端验收基于 macOS 上 bundle ID 为 `com.openai.codex` 的 `26.908.40834` 构建。新增加的安装路径识别经过自动测试；其他 Codex 发行版、后续版本，以及 Windows / Linux 的桌面注入兼容性尚未验证。内部消息桥、页面 URL 或侧栏结构变化时可能无法挂载。

## 检测规则：先知道它在测什么

卡片沿用「智商检测」这个实验名称，但它是 **固定知识题与规则解析器**，不构成智力测量、模型身份鉴定或服务质量证明。提示措辞、知识截止时间和回答的不确定性都可能影响结果。

检测只发送以下原句，不附带答案示例或格式要求：

> 不要调用任何外部工具，按你的已有知识，Gemini 的最新版本是什么？

| 回答情况 | 卡片判定 |
| --- | --- |
| 明确确认 3 系列，例如 `3`、`3.`、`3.0`、`3.1` | 正常 |
| 明确确认 2 系列或更早版本 | 异常 |
| 明确确认 4 或更高主版本 | 正常，沿用主版本 ≥ 3 的规则 |
| 没有明确版本、出现冲突结论或无法保守解析 | 无法判定，查看原文 |
| 检测过程中出现工具执行项 | 检测无效 |
| 网络、额度或模型错误 | 请求失败，不当作检测结论 |

这些是本项目约定的阈值，**不代表已经联网核实 Gemini 的实际最新版本**。解析器支持自然语言和 Markdown，但复杂的否定、猜测或历史叙述仍可能需要人工核对。

「恢复智商」发送的是一条要求模型直接给出 323 个 1–355 整数、禁止工具的固定提示，全文见 [core.cjs 的 `RECOVER_PROMPT`](core.cjs)。程序只验证数量和边界；**没有证据表明这能恢复模型能力，也不证明输出具有随机性**。完成后显示待复测，不会自动多发一次检测。

模型列表来自宿主实际返回的目录。GPT-6 的可见推理强度沿用当前界面文案：轻度、中、高、极高、最高；具体可用选项仍以目录为准。

## 更新、停用与常见问题

**更新源码**：

```sh
git pull --ff-only
npm run build:launcher
```

再次打开统一入口即可。同一仓库路径下，同版本加载器会复用，新版本会替换旧加载器。正在进行的请求先收尾再更新卡片，不需要日常先运行 Stop。

**提示 Codex 已运行但无法注入？** 用 ⌘Q 完全退出，再通过统一入口打开。入口不会强制关闭已有任务。调试端口固定为本机 `9222`，被其他应用占用时需要先解决冲突。

**桌面同名入口已存在？** 构建只会更新指向当前仓库 App 的替身或旧软链接，不覆盖普通文件、文件夹或其他安装位置的入口。先将旧入口移开；只想构建、不创建桌面入口时运行 `npm run build:check`。

**请求超时或归档失败？** 点击「检查并收尾」或「重试归档」，程序会读取原任务。创建请求超时且没有拿到任务 ID 时，先在 Codex 任务列表核对，再清除卡片的等待记录。切换账号后无法确认归属的旧结果不会显示为当前账号的检测结论。

**额度或 Tibo 消息读取失败？** 展开对应区域查看状态并重试。到达账号重置时间后，卡片等待额度接口更新；预告到期后等待确认，不自动假定重置已经到账。

**停用**：先在卡片中完成请求收尾，再运行以下命令，随后完全退出 Codex、通过原始图标重新打开。

```sh
npm stop
```

停止后台不会中断已提交的模型任务，也不会立即移除页面中已经挂载的卡片。在加载器已停止、请求已收尾时，可用 `npm run remove` 移除当前页面卡片。

**卸载**：停用后删除桌面替身和仓库目录。日志与进程记录位于 `~/Library/Application Support/Codex IQ Card`，可按需另行删除。未完成任务记录保存在 Codex 页面的本地存储中，先通过卡片收尾；已归档任务仍可在 Codex 中查看。

## 数据与运行边界

- CDP 调试接口绑定回环地址，加载器只接受同端口的本机 WebSocket，并筛选已知 Codex 主页面。CDP 拥有较强的页面控制能力，请勿将 `9222` 转发或暴露到公网；其他本机进程仍可能访问它。
- 不读取 Codex 的凭据文件，不更改安装包、ASAR、签名或页面 CSP，不注册登录项。
- 账号额度通过宿主消息桥读取，仅保存在页面内存中，切换账号会清空旧值。未完成检测会把任务 ID、选项和已收到的回答暂存到页面本地存储，用于恢复收尾。
- 后台每五分钟匿名读取 [AIHOT 公开重置接口](https://aihot.news/api/v1/codex-resets)，不附带账号、额度或令牌。AIHOT 作为第三方数据源会收到普通网络请求及来源 IP。公开消息不等同于个人账号的到账承诺。
- 本项目没有额外的登录服务或遥测上报。日志仅写入本机，超过 512 KB 在下次启动时轮换。

## 开发与验证

在 macOS 源码目录运行：

```sh
# 只生成应用，测试过程不触碰桌面入口、不启动 Codex
npm run build:check
npm test
npm run test:launcher

# 检查本路径管理的加载器
npm run status
```

测试覆盖版本解析、额度窗口、公开重置状态、跨窗口任务互斥、账号切换、归档失败恢复、CDP 目标隔离、后台进程和原生替身。macOS 替身测试依赖已经构建的 App；其他系统会跳过原生检查，不代表支持桌面注入。

提供一个使用 **真实卡片代码与模拟桥** 的交互预览，不会发起模型请求或读取真实账号：

```sh
# 如已安装 Python 3，从仓库根目录启动
python3 -m http.server 8742 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8742/preview.html>，可模拟正常、异常、工具调用、额度错误与归档失败。预览里的模型名称、额度和重置消息均是演示数据。

架构、调用链与状态边界见 [docs/architecture.md](docs/architecture.md)。图标由 [build-icon.swift](build-icon.swift) 生成，运行方式见开发文档。

欢迎提交 Issue 或 PR。报告兼容性问题时请附 macOS、Node 和 Codex 版本，以及经过脱敏的错误信息；不要上传账号凭据、完整会话或个人任务记录。
